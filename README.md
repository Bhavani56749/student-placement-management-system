# Student Placement Management System

A web-based Student Placement Management System developed to centralize and organize college placement activities through dedicated student and administrator portals.

The system allows students to register, log in, manage their profile, education and skills, view available jobs, apply for opportunities, view submitted applications, and track placement progress.

The administrator can manage student records, companies, job postings, applications, application status, remarks, and student-wise placement status.

## Features

### Student Portal

- Student registration and login
- Student profile management
- Education information
- Skill management
- View available jobs
- View company information
- Apply for jobs
- Application history
- Application status tracking
- Placement status monitoring

### Admin Portal

- Administrator login
- View student records
- Company management
- Add, update, search and delete jobs
- View all student applications
- Search applications
- Update application status
- Add application remarks
- Delete applications
- Student-wise placement status
- Dashboard statistics

## Main Modules
