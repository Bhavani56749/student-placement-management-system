STUDENT PLACEMENT MANAGEMENT SYSTEM
===================================

FINAL PROJECT REQUIREMENTS / IMPLEMENTATION SUMMARY

1. PROJECT OVERVIEW
-------------------

The Student Placement Management System is a web-based application developed
for managing college placement activities in a centralized and organized manner.

The system provides separate portals for students and administrators. Students
can register and log in, maintain their profile, education details and skills,
view available job opportunities, apply for jobs, view their applications, and
track application and placement status.

Administrators can log in and manage students, companies, job postings,
applications, application statuses, and overall student placement status.

The system uses a Java backend connected to a MySQL database, with an HTML, CSS,
and JavaScript frontend.


2. PROBLEM STATEMENT
--------------------

Placement information may be maintained manually using spreadsheets or multiple
separate records. This can make it difficult to organize student information,
company information, job opportunities, applications, and selection status.

Manual management can create difficulties in:

- Maintaining student records
- Managing company information
- Managing job postings
- Tracking student applications
- Updating application status
- Monitoring placement progress
- Providing a centralized view of placement information

Therefore, a centralized placement management system is required to simplify
and organize the placement process.


3. PROPOSED SOLUTION
--------------------

The proposed system provides a centralized web-based platform for placement

The completed system provides:

- Student registration and login

------------------------

The Authentication Module provides separate login functionality for students
and administrators.

Student authentication includes:

- Student email and password login

Admin authentication includes:

- Admin email and password login
- Validation against the admin record stored in MySQL

----------------------------

The Student Management Module stores and displays student information such as:

- Student ID
- Full name
- Email
- Phone number
- Department
- Graduation year
- CGPA
- Address
- Other profile information

The admin can view student records through the Admin Portal.


8. EDUCATION MODULE
-------------------

The Education Module stores academic information associated with a student.

Education information includes:

- Qualification
- Institution
- Specialization
- Passing year
- Percentage

Students can view their education information in the student portal.


9. SKILL MANAGEMENT MODULE
--------------------------

The Skill Management Module stores technical skills and connects students

Examples of skills used in the project include:

- Java
- Python
- SQL
- HTML
- JavaScript
- Excel
- Data Analysis
- CSS
- Machine Learning
- Tableau


10. COMPANY MANAGEMENT MODULE
-----------------------------

The Company Management Module allows the administrator to manage company

Company information includes:

- Company ID
- Company name
- Industry
- Location
- Website
- Contact person
- Contact email

Admin operations include:

- Add company
- View companies
- Search companies
- Update company information
- Delete company information when permitted by database relationships

Students can view available company information through the Student Portal.


11. JOB MANAGEMENT MODULE
-------------------------

The Job Management Module allows administrators to manage placement
opportunities.

Job information includes:

- Job ID
- Company
- Job title
- Job description
- Required skills
- Minimum CGPA
- Eligible department
- Graduation year
- Salary package (LPA)
- Application deadline
- Job location

Admin operations include:

- Add job
- View jobs
- Search jobs
- Update job
- Delete job

The job information is shared with the Student Portal so that students can
view available opportunities.


12. JOB APPLICATION MODULE
--------------------------

Students can apply for placement opportunities through the Available Jobs
page.

The system stores:

- Application ID
- Student ID
- Job ID
- Application date
- Application status
- Remarks

The system also prevents the same student from applying to the same job more
than once.

Implemented application statuses are:

- Applied
- Shortlisted
- Selected
- Rejected

The administrator can update the application status and remarks.


13. PLACEMENT STATUS MODULE
---------------------------

The system provides a student-wise placement status view.

For each student, the admin can view:

- Student ID
- Student name
- Department
- CGPA
- Total applications
- Applied applications
- Shortlisted applications
- Selected applications
- Rejected applications
- Overall placement status

The overall status is calculated from the student's application records.

The implemented overall statuses are:

- Placed
- In Process
- Not Selected
- No Applications

A student is treated as Placed when at least one application is Selected.
A student is treated as In Process when an Applied or Shortlisted application
exists and no application is Selected. A student with applications that are all
Rejected is treated as Not Selected. A student with no applications is treated
as No Applications.


14. ADMIN DASHBOARD MODULE
--------------------------

The Admin Dashboard provides a centralized summary of placement information.

The dashboard displays live counts such as:

- Total students
- Total companies
- Total jobs
- Total applications

The detailed placement and application information is available through the
Admin Placement Status and Manage Applications pages.


15. FRONTEND TECHNOLOGIES
-------------------------

The frontend is developed using:

- HTML
- CSS
- JavaScript

HTML is used for page structure, CSS for styling, and JavaScript for page
interactions and communication with the backend APIs.


16. BACKEND TECHNOLOGIES
------------------------

The backend is developed using:

- Java
- Java HttpServer (com.sun.net.httpserver.HttpServer)
- JDBC

The backend exposes HTTP endpoints for authentication, student information,
education, skills, companies, jobs, applications, and related operations.


17. DATABASE TECHNOLOGY
-----------------------

The project uses:

- MySQL
- JDBC for database connectivity
- MySQL Workbench for database management and testing

The Java backend connects to the MySQL database through JDBC.


18. APPLICATION ARCHITECTURE
----------------------------

The application follows a layered structure:

Frontend
   ↓
HTTP API / Java HttpServer
   ↓
Controller Layer
   ↓
Service Layer
   ↓
DAO Layer
   ↓
MySQL Database

This structure separates the user interface, request handling, business logic,
data-access operations, and database storage.


19. DATABASE ENTITIES
---------------------

The implemented database design includes records for the following main areas:

1. Student
   Stores student personal, academic and account information.

2. Education
   Stores academic records associated with students.

3. Skill
   Stores available technical skills.

4. Student_Skill
   Associates students with their skills and proficiency levels.

5. Company
   Stores company information.

6. Job
   Stores job and placement opportunity information.

7. Application
   Stores student job applications, application status, and remarks.

8. Admin
   Stores administrator login information.


20. DATABASE RELATIONSHIPS
--------------------------

The main relationships used by the system are:

1. One company can have many job postings.
2. One student can submit many applications.
3. One job can receive many applications.
4. One student can have multiple education records.
5. Students and skills have a many-to-many relationship through Student_Skill.
6. Applications connect students with jobs.
7. Admin records are used for administrator authentication.

Primary keys uniquely identify records, while foreign keys connect related
records where applicable.

26. CONCLUSION
--------------

The Student Placement Management System successfully provides a centralized
platform for student placement activities. The project integrates an HTML,
CSS, and JavaScript frontend with a Java backend and MySQL database.

Students can manage their placement-related information, view jobs, submit
applications, and track their status. Administrators can manage students,
companies, jobs, applications, and placement progress. The successful
Student-to-Admin-to-MySQL-to-Student status update flow demonstrates that the
main modules work together as an integrated system.
